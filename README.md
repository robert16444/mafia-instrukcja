Dokumentacja będzie sukcesywnie aktualizowana wraz z rozwojem narzędzi, zmianami w mechanikach gry oraz pojawianiem się nowych procedur.

Jeśli zauważysz nieaktualną instrukcję, brakujące informacje lub błąd:

1. Zgłoś problem osobie odpowiedzialnej za dokumentację.

3. Jeśli to możliwe, dołącz zrzut ekranu lub przykład.
